## 📦 1번 타자: DanCraft (단크래프트) 퀵스타트

```bash
# 1. 단크래프트 디렉토리 이동
cd dancraft

# 2. 파이썬 원클릭 엔진 실행
python scripts/dancraft_engine.py <이미지경로> <출력폴더>

# 3. 기능형 웹 스튜디오 실행
cd web_studio
python server.py
# 브라우저에서 http://localhost:8501 접속
```
