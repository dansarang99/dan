## 🌟 핵심 특징
1. **법적 리스크 0% (Pure Functional Studio)**: ArtCraft의 상표나 비공개 코드를 일체 도용하지 않은 순수 자체 제작 기능형 웹 스튜디오.
2. **원클릭 누끼 & 4컬러 프리뷰**: 이미지 업로드 즉시 원본, 스텔스 블랙, 크림슨 레드, 코발트 블루 실시간 시각적 검증.
3. **포토샵 마스터 파일(.PSD) 직결**: 브라우저에서 바로 공식 멀티레이어 PSD 내보내기 지원.
4. **모달 연동 제로토발 브리지**: 발열 0% 상온 사수 원격 GPU 생성 연동.

---

## 🚀 로컬 실행 방법
```bash
python server.py
# 브라우저에서 http://localhost:8501 접속
```
또는 `index.html` 파일을 크롬/엣지 브라우저로 더블 클릭만 해도 즉시 실행됩니다!
