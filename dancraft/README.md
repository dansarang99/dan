## 🌟 개요

**DanCraft (단크래프트)**는 유료 결제벽(Paywall)과 무거운 설치 없이, 단 10초 만에 (1) U2Net AI 초정밀 0초 누끼 분리 (2) 4대 시그니처 컬러(원본, 스텔스 블랙, 크림슨 레드, 코발트 블루) 외과수술적 리메이크 (3) 어도비 포토샵 정식 다중 레이어(.PSD) 자동 컴파일 (4) 모달 연동 제로토발(Zero-Token, Zero-Heat) 원격 고화질 생성 브리지를 엔드투엔드로 완결하는 차세대 올인원 크리에이티브 IDE입니다.

## 🚀 빠른 시작

### 1. 코어 엔진 CLI 실행
```bash
python scripts/dancraft_engine.py <이미지경로> <출력폴더>
```

### 2. 웹 스튜디오 실행
```bash
cd web_studio
python server.py
# 브라우저에서 http://localhost:8501 접속
```
